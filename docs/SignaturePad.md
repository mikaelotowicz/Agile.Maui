# Agile.Maui.SignaturePad

Project for `SignaturePad`, a reusable signature capture control for .NET MAUI.
It captures strokes as vector data, supports variable-width ink, records timing
and pressure metadata when the platform provides it, and exports the signature as
PNG or JPEG.

Assembly: `Agile.Maui.SignaturePad`  
C# namespace: `Agile.Maui`  
Registration: `builder.UseAgileSignaturePad()`

## Overview

`SignaturePad` is built on top of MAUI `GraphicsView`. The drawing and export
logic is shared by all platforms, while a small native interop layer captures
touch, stylus, and pointer input with pressure where available.

This keeps the public API consistent across Android, iOS, macOS Catalyst, and
Windows without requiring a full custom handler per platform.

## Features

- Freehand signature capture.
- Variable-width strokes based on velocity and physical pressure when available.
- Vector stroke storage for replay, undo, redo, and export.
- Biometric metadata: points, timestamps, pressure values, and pressure source.
- PNG export with transparent background support.
- JPEG export with configurable quality.
- Optional crop-to-content export.
- Optional signature line and empty-state prompt.
- Bindable `IsEmpty` state for forms and validation.
- `StrokeCompleted` event and command support.

## Requirements

- .NET MAUI / .NET 10.0 with package `Agile.Maui.SignaturePad` `1.0.4`.
- .NET MAUI / .NET 11.0 preview with package `Agile.Maui.SignaturePad` `1.0.4-preview.1`.
- Android API 21+.
- iOS 15.0+.
- macOS Catalyst 15.0+.
- Windows 10.0.17763.0+.

## Installation

```powershell
dotnet add package Agile.Maui.SignaturePad --version 1.0.4
```

For .NET 11 preview projects:

```powershell
dotnet add package Agile.Maui.SignaturePad --version 1.0.4-preview.1
```

Register the component in `MauiProgram.cs`:

```csharp
using Agile.Maui;

builder
    .UseMauiApp<App>()
    .UseAgileSignaturePad();
```

The registration is required because it attaches the native touch/pressure input
interop to the MAUI `GraphicsView` used by `SignaturePad`.

Add the XAML namespace:

```xml
xmlns:signature="clr-namespace:Agile.Maui;assembly=Agile.Maui.SignaturePad"
```

## Quick Example

```xml
<Border
    BackgroundColor="White"
    HeightRequest="240"
    Stroke="#DDDDDD"
    StrokeThickness="1">
    <Border.StrokeShape>
        <RoundRectangle CornerRadius="12" />
    </Border.StrokeShape>

    <signature:SignaturePad
        x:Name="Signature"
        BackgroundColor="White"
        MinStrokeWidth="1.5"
        MaxStrokeWidth="7"
        PromptText="Sign here"
        ShowSignatureLine="True"
        StrokeColor="#111111" />
</Border>
```

## Export Example

```csharp
if (Signature.IsEmpty)
    return;

var options = new SignatureExportOptions
{
    CropToContent = true,
    Padding = 20,
    Scale = 2.0,
    BackgroundColor = null,
};

using var stream = await Signature.GetImageStreamAsync(
    SignatureImageFormat.Png,
    options);
```

For JPEG export, transparency is not supported. If `BackgroundColor` is `null`,
the component uses a white background.

## Properties

| Property | Type | Default | Description |
|---|---|---|---|
| `StrokeColor` | `Color` | `Black` | Color used for new strokes. |
| `MinStrokeWidth` | `double` | `1.0` | Minimum stroke width in DIP, usually reached by faster movement. |
| `MaxStrokeWidth` | `double` | `3.5` | Maximum stroke width in DIP, usually reached by slower movement or higher pressure. |
| `VelocityFilterWeight` | `double` | `0.7` | Exponential smoothing weight for velocity-based stroke width. Clamped internally to `0..1`. |
| `ShowSignatureLine` | `bool` | `false` | Shows a guide line while the pad is empty. |
| `SignatureLineColor` | `Color` | `Gray` | Color of the guide line. |
| `PromptText` | `string?` | `null` | Text shown while the pad is empty. |
| `PromptTextColor` | `Color` | `Gray` | Prompt text color. |
| `StrokeCompletedCommand` | `ICommand?` | `null` | Command executed when a stroke is completed. Receives `StrokeCompletedEventArgs`. |
| `IsEmpty` | `bool` | `true` | Read-only bindable state indicating whether the pad has completed strokes. |

`SignaturePad` inherits from `GraphicsView`, so standard MAUI visual properties
such as `BackgroundColor`, `HeightRequest`, `WidthRequest`, `Margin`, and
`IsEnabled` are also available.

## Methods

| Method | Description |
|---|---|
| `Clear()` | Removes all strokes and resets the signature state. |
| `Undo()` | Removes the last completed stroke and places it on the redo stack. |
| `Redo()` | Restores the last undone stroke. |
| `GetSignatureData()` | Returns a `SignatureData` snapshot with strokes, points, timestamps, pressure metadata, and canvas size. |
| `GetStrokes()` | Returns the completed strokes only. |
| `GetSignatureJson(bool indented = false)` | Serializes the signature biometric/vector data to a stable JSON document. |
| `LoadSignatureJson(string)` | Restores strokes from JSON generated by `GetSignatureJson`. |
| `LoadStrokes(IEnumerable<SignatureStroke>)` | Replaces the current content with existing strokes and recalculates render widths. |
| `GetImageStreamAsync(SignatureImageFormat, SignatureExportOptions?)` | Exports the signature as PNG or JPEG. The returned stream is positioned at the beginning and must be disposed by the caller. |

## Events

| Event | Description |
|---|---|
| `StrokeCompleted` | Raised after the user lifts the finger, mouse, or stylus and a stroke is committed. |
| `Cleared` | Raised after `Clear()` removes all strokes. |

## Data Model

### SignaturePoint

Represents one captured sample.

| Property | Description |
|---|---|
| `X` | X coordinate in DIP, relative to the pad. |
| `Y` | Y coordinate in DIP, relative to the pad. |
| `TimestampMs` | Milliseconds since the first stroke in the signature session. |
| `Pressure` | Normalized pressure value from `0` to `1`. |
| `PressureSupported` | `true` when the value came from physical pressure reported by hardware; `false` when it was derived from velocity. |

When physical pressure is not available, `Pressure` is a velocity-derived proxy.
Do not treat it as hardware pressure unless `PressureSupported` is `true`.

### SignatureStroke

Represents a continuous stroke from touch-down to touch-up.

| Property | Description |
|---|---|
| `Points` | Ordered list of `SignaturePoint`. |
| `Color` | Stroke color. |
| `DurationMs` | Difference between the first and last point timestamp. |

### SignatureData

Represents a complete signature snapshot.

| Property | Description |
|---|---|
| `Strokes` | Completed strokes in drawing order. |
| `CanvasSize` | Pad size in DIP at capture time. |
| `TotalPoints` | Total point count across all strokes. |
| `TotalDurationMs` | Time elapsed between first and last sample. |
| `HasRealPressure` | `true` when at least one point reported physical pressure. |

## JSON Persistence

The component keeps biometric/vector data only in memory while the control is
alive. It does not automatically write signatures to disk, a database, or a
remote service.

Use `GetSignatureJson()` when the application needs to persist the captured data
alongside the exported image and audit records:

```csharp
var signatureJson = Signature.GetSignatureJson(indented: true);
```

The JSON contains:

- `version`;
- canvas width and height in DIP;
- strokes in drawing order;
- stroke color as `#AARRGGBB`;
- every captured point with `x`, `y`, `timestampMs`, `pressure`, and
  `pressureSupported`.

Restore the signature later with:

```csharp
Signature.LoadSignatureJson(signatureJson);
```

Store this JSON together with the rendered PNG/JPEG and the application audit
data, such as user, document hash, timestamp, device, and session identifiers.

Coordinates are restored in the same DIP coordinate space in which they were
captured. If the target pad has a different size, normalize or scale the points
in the application layer before loading.

## Export Options

`SignatureExportOptions` controls image generation.

| Property | Type | Default | Description |
|---|---|---|---|
| `CropToContent` | `bool` | `true` | Exports only the bounds containing strokes plus padding. |
| `Padding` | `double` | `16` | Padding in DIP around cropped strokes. |
| `Scale` | `double` | `2.0` | Export resolution multiplier. |
| `BackgroundColor` | `Color?` | `null` | Export background. `null` keeps PNG transparent. |
| `StrokeColorOverride` | `Color?` | `null` | Forces a stroke color during export. Useful for black-only signatures. |
| `JpegQuality` | `float` | `0.9` | JPEG quality from `0` to `1`. |

## Platform Behavior

| Platform | Input source | Notes |
|---|---|---|
| Android | `MotionEvent` | Uses `GetPressure()` and replays historical batched points for smoother strokes. Pressure is considered physical for stylus/eraser input. |
| iOS | `UITouch` | Uses `Force / MaximumPossibleForce` when available, including Apple Pencil. Replays coalesced touches so high-frequency input (Apple Pencil reports well above the ~60 Hz touch event rate) is captured faithfully. |
| macOS Catalyst | `UITouch` | Shares the iOS interop implementation. |
| Windows | `PointerRoutedEventArgs` | Uses `PointerPoint.Properties.Pressure` for pen input and pointer capture during drawing. Replays intermediate points coalesced between pointer events so fast pen strokes are captured faithfully. |

## Architecture

The component uses three layers:

| Layer | Responsibility |
|---|---|
| `SignaturePad` | Public control, state management, touch sample ingestion, undo/redo, export. |
| `SignaturePadDrawable` | Shared drawing logic using `ICanvas`, including stroke smoothing and guide rendering. |
| `Platforms/*/SignatureTouchInterop` | Minimal native input bridge for touch, stylus, mouse, timestamps, and pressure. |

The native interop is attached through `GraphicsViewHandler.Mapper.AppendToMapping`
inside `UseAgileSignaturePad()`. It only affects instances of `SignaturePad`.

## Form Validation

Use `IsEmpty` to validate required signatures:

```csharp
if (Signature.IsEmpty)
{
    await DisplayAlert("Signature", "Please sign before continuing.", "OK");
    return;
}
```

In MVVM scenarios, bind to `IsEmpty` as a read-only state from the view.

## Legal And Audit Notes

`SignaturePad` only captures the drawn signature and its technical data. Legal
validity depends on the complete signing flow used by the application.

For stronger auditability, store the signature image, signature JSON, signed
document hash, user identity, consent, timestamp, and session/device data when
appropriate. Use a digital certificate or trusted signing provider when the
document requires it.

## Notes

- Give the pad a stable size, usually with `HeightRequest`, so drawing and export
  have predictable dimensions.
- Wrap the pad in a `Border` when you need visual framing or rounded corners.
- `LoadStrokes` restores geometry in the coordinate space in which the strokes
  were captured. If replaying into a different size, normalize coordinates in the
  application layer before loading.
- The guide line and prompt are visible only while the pad is empty and are not
  exported as part of the image.
